# Ducky.Localization sample mod

Brief description

This example shows how to define and organize localization keys in a standalone mod and how to put translations into assets for runtime use.Entry and key definitions are shown in ['Ducky.Localization/ModBehaviour.cs'](Ducky.Localization/ModBehaviour.cs:1) with ['Ducky.Localization/LK.cs'](Ducky.Localization/LK.cs:1)。

Before you start

Please read and prepare your development environment first：[`docs/Prequirement.md`] (docs/Prequirement.md:1)。

Project Structure (Key Points)

- [`Ducky.Localization/ModBehaviour.cs`] (Ducky.Localization/ModBehaviour.cs:1) — Mod entry that demonstrates how to reference localized strings.
- [`Ducky.Localization/LK.cs`] (Ducky.Localization/LK.cs:1) — Static localized key definitions (recommended to be maintained in code).
- [`Ducky.Localization/assets/`] (Ducky.Localization/assets/:1) — Contains resources such as translation CSV, document-based translations, and descriptions.

Localization Key (LK.cs)

- In ['Ducky.Localization/LK.cs'](Ducky.Localization/LK.cs:1) using static constant organization keys (eg：UI classification).
- Long text can be translated as a file using the '[TranslateFile("md)]]' annotation (which generates 'assets/Locales/{lang}/' in the file).
- To declare a supported language, use the [LanguageSupport("en","en","zh-hant")]' attribute (if desired).

Translate files and generate

- Translate CSV：\`assets/Locales/{lang}.csv', in the format Key, Value.
- Document-based translation：Placed in 'assets/locales/{lang}/', CSV median is referenced by the file name, for example：`"ducky.singleproject.ui.longdescription.md"`。
- 'assets/lkeys.json' and 'assets/keys.hash.txt' will be generated by the SDK's MSBuild at compile time for runtime positioning and packaging checks, so please do not edit them manually.

Recommended workflows

- Add or modify keys in your code (recommended)：Edit ['Ducky.Localization/LK.cs'](Ducky.Localization/LK.cs:1) and compile, and the SDK updates the translation metadata.
- Or edit 'assets/locales/ directly'{lang}.csv' and recompile to allow the SDK to integrate the changes.

Usage examples

```csharp
using Ducky.Sdk.Localizations;
var message = L.UI. NiceWelcomeMessage; Resolves to a translation of the current language at runtime
```

Build and run

```bash
dotnet build Ducky.Localization/
# or build the entire solution
dotnet build Docky.Sdk.Sample.slnx
```

remark

- Make sure '.csproj' is set to '<ModName>' with the general project attribute (see other example projects).
- Long texts are recommended to use file-based translation for better maintenance in source code repositories.
