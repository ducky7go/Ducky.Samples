# Ducky.Localization サンプル MOD

Short description

This example shows how to define and organize localization keys in a standalone mod, and how to put translations into assets for use in runtime.The entry and key definitions are defined in ['Ducky.Localization/ModBehaviour.cs'](Ducky.Localization/ModBehaviour.cs:1) を ['Ducky.Localization/LK.cs'](Ducky.Localization/LK.cs:1)。

Before you begin

First, read the development environment and prepare it：['ドキュメント/Prequirement.md'] (docs/Prequirement.md:1)。

Project Structure (Points)

- ['ダッキー.ローカライゼーション/ModBehaviour.cs'] (Ducky.Localization/ModBehaviour.cs:1— A mod entry that shows how to reference a localized string.
- ['Ducky.Localization/LK.cs'] (Ducky.Localization/LK.cs:1— Statically localized key definitions (recommended to be maintained in code).
- ['Ducky.Localization/assets/'] (Ducky.Localization/assets/:1— Includes resources such as translation CSV, document-based translations, and explanations.

ローカライズキー(LK.cs)

- ['Ducky.Localization/LK.cs'] (Ducky.Localization/LK.cs:1) using a static constant organization key (e.g.：UI classification).
- Long text can be found in the '[TranslateFile("md)]]' annotation ('assets/Locales/{lang}/') as a file.
- To declare a supported language, use the LanguageSupport("en","en","en-hant")]' attribute (if required).

Translate and generate files

- Translate CSV：'assets/ロケール/{lang}.csv', in the form of keys and values.
- Document-based translation：「assets/locales/{lang}/', the CSV median is referenced by the file name (e.g.,：'"ducky.singleproject.ui.longdescription.md"'。
- 'assets/lkeys.json' and 'assets/keys.hash.txt' should not be manually edited as they are generated by the SDK's MSBuild at compile time for runtime positioning and packaging checks.

Recommended workflow

- Add or change keys in your code (recommended)：['Ducky.Localization/LK.cs'] (Ducky.Localization/LK.cs:1) and the SDK updates the translation metadata.
- Or edit 'assets/locales/ directly'{lang}.csv" and recompile it so that the SDK can integrate the changes.

Use Cases:

```csharp
Use Ducky.Sdk.Localizations.
var message = L.UI です。 ナイスウェルカムメッセージ; It resolves to the translation of the current language at runtime
```

Build and run

```bash
dotnet build Ducky.Localization/
# or build the entire solution
dotnet build Docky.Sdk.Sample.slnx
```

See

- Make sure '.csproj' is set to '.<ModName>' with the General project attribute (see other project examples).
- For long text, it is recommended to use file-based translation to improve the maintenance of the source code repository.
